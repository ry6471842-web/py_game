.Python Slot Machine

A simple console-based slot machine game built with Python.
The game lets you place a bet, spin the reels, and check whether the three symbols match to determine your winnings. It is a small project created to practice Python fundamentals such as functions, loops, dictionaries, randomization, and user input.

.How It Works

1. Choose how many lines you want to bet on.
2. Enter your bet amount.
3. Spin the slot machine.
4. The reels generate random symbols.
5. Matching symbols result in a payout.
6. Your balance is updated based on your winnings.

eg.
🎰 A | A | A 🎰
You won!
